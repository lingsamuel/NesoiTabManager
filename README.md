# Nesoi 标签管理器

一个用于管理海量标签页的 Chrome/Edge 扩展。

## 需求

- 读取所有窗口与标签页。
- 可勾选多个标签页保存到列表。
- 支持保存到已有列表或新建列表。
- 保存时可选择关闭标签页。
- 支持导入、导出已保存的标签页。
- 点击扩展按钮在新标签页打开管理界面，避免弹窗过小。
- 网页右键菜单提供：
  - 保存到某个列表
  - 关闭并保存到某个列表
- 网页左下角悬浮组件：
  - 鼠标划过向上展开已有列表
  - 一键保存或关闭并保存当前页面
- AI 辅助分组（手动触发）：
  - 发送标签页标题与基础域名，结合打开顺序生成标签
  - 标签展示在标签页列表旁，可一键应用生成新列表（不影响原列表）
- 管理界面采用侧边栏分区：打开的窗口、保存的列表、插件设置；前两者提供子侧边栏快速切换。
- 交互文案统一使用中文。

## 实现说明

- Manifest V3，后台使用 service worker。
- 使用 `chrome.tabs`、`chrome.storage`、`chrome.contextMenus`。
- 列表数据存放在 `chrome.storage.local`。
