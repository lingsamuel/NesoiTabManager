# 管理界面（Vue）

## 布局结构
- 侧边栏：主导航（打开的窗口 / 保存的列表 / 冻结历史 / 近期标签页 / 插件设置）。
- 子侧边栏：在“窗口/列表”视图下显示窗口或列表的快速切换入口。
- 主内容区：各视图面板 + 多个操作弹窗。
- 滚动条轨道刻度：与侧边栏同一套实现（`src/manager/utils/scroll_markers.js` + `src/manager/styles/track_marks.css`），
  只是滚动条在右侧（`.track-marks.on-right`）。
  - **每个窗口各画一条蓝色刻度**指向该窗口的活动标签（管理页本来就是多窗口视图）；
    活动标签被折叠或被筛选隐藏时，退回到它**最近的可见祖先行**（该行同时加一圈蓝边）。
  - 跳转模式下的搜索匹配项画琥珀色刻度、当前匹配项高亮；距离小于 6px 的刻度合并（规则见 `docs/ui/firefox_sidebar.md`）。
  - 点击刻度会滚动到该行；点到匹配刻度时同步「当前跳转项」。
  - **轨道高度必须在滚动容器出现后再测量**：`TabListPanel` 是常驻组件（`WindowsView` 用 `v-show` 渲染，
    启动时 `rows` 为空、渲染的是空状态分支），因此不能只在 `onMounted` 挂 `ResizeObserver`——
    那时滚动容器还不存在，观察器无处可挂，`trackHeight` 会一直是 0，所有刻度的比例位置都算成 0、
    叠在顶端并被合并成一条。改为 `watch(wrapperRef)`，容器出现时再挂上。
    轨道高度未知时（含被 `v-show` 隐藏的视图）一律不画刻度，避免出现"全挤在一起"的假象。
  - 哪些视图有刻度：`TabListPanel` 是共用组件，因此**所有带筛选的列表视图**（Windows / 最近 / 历史）都会有匹配刻度，
    但只有「打开的窗口」视图会传 `activeRows`，因此只有它有蓝色活动刻度。
  - 「打开的窗口」视图关闭了列表的自动滚动（`auto-scroll-to-match=false`）并改为显式滚动，
    这样才能支持"滚动时当前项跟随可见范围"而不与用户抢滚动条；其它视图保持"当前项变化即自动滚动"。
  可见区间由 `src/manager/utils/virtual_range.js` 计算，并且明确保证两点：滚动位置一定被夹进内容范围、只要还有行可见区间就不为空——否则滚动位置与真实 DOM 一旦不同步，列表会整片空白、滚动一下才恢复。

## 打开的窗口（Windows）
- 列表展示：按窗口分块显示标签，包含图标、标题、URL、固定/冻结标识与冻结次数。
  站点没有 favicon（或加载失败）时显示内置占位图标，见 `docs/ui/firefox_sidebar.md` 的「favicon 占位图」。
- 展示模式：标题栏提供「树状 / 平铺」切换，默认树状；选择记入 `chrome.storage.local` 的 `treeViewMode`。
- 选择操作：支持全选/清空、行点击切换选中、复选框精确选择。
- 批量动作：关闭所选、冻结所选、移动到窗口、保存所选、AI 分组。
- 过滤能力：可隐藏已冻结标签页（便于聚焦活跃标签）。
- 筛选输入框：按标题/网址过滤标签，无匹配的窗口分组整组隐藏。
- 拖拽交互：
  - 平铺模式：拖拽标签到另一个标签上，会插入到该标签之后；拖拽已选标签时，会整体移动选中集合。
  - 树状模式：按落点分区改变父子关系（行上 1/4 → 前一个兄弟、行下 1/4 → 后一个兄弟、行中间 1/2 → 子标签），被拖标签的整棵子树一起移动；仅限同窗口。
- 单条动作：行内支持关闭与手动冻结；点击标题/URL 会激活该标签。

## 树状模式（Tree）
- 渲染顺序：树的 DFS 顺序（父 → 整棵子树 → 下一个兄弟），兄弟之间按标签 `index` 升序；行高仍为 44px，层级用缩进与连线表示。
- 折叠：有子标签的行显示折叠三角，点击折叠/展开；折叠状态存 `chrome.storage.session`，仅当前浏览器会话有效。
- 筛选交互：过滤模式下保留「匹配项 + 全部祖先」；只要存在关键词（过滤与跳转模式都算）就忽略折叠状态，保证匹配项可见；开启「隐藏已冻结」时，父标签不可见的子标签会提升到最近的可见祖先之下。
- 全选口径：过滤模式只作用于真正匹配的标签（祖先只是路径），跳转模式作用于完整列表。
- 数据模型、父子推断规则、持久化与写入节流策略见 `docs/ui/tree_style_tabs.md`。
- Firefox 另提供原生侧边栏作为同一棵树的常驻入口，见 `docs/ui/firefox_sidebar.md`。

## 保存的列表（Lists）
- 列表切换：子侧边栏显示全部列表与数量；支持新增列表入口。
- 列表标题编辑：点击标题进入编辑态，可保存或取消。
- 列表描述：单独面板维护描述信息，用于 AI 分组参考。
- 列表内容：
  - 行内复选框 + 点击选中，支持批量删除与移动。
  - 支持直接打开保存项（新窗口打开链接）。
  - 批量删除与删除列表带确认提示，单条删除即时生效。
- 导入/导出：
  - 导出为 JSON 文件。
  - 导入支持“合并/替换”两种模式。
- 筛选输入框：按标题/网址过滤当前列表内的保存项。

## 冻结历史（History）
- 分批展示：按冻结批次分段，展示冻结时间与包含条数。
- 批量动作：全选/清空、关闭所选、AI 分组、保存所选、刷新。
- 行内动作：可对历史标签执行关闭或激活。
- 状态提示：刷新与错误提示在顶部状态条展示。
- 筛选输入框：按标题/网址过滤记录，无匹配的冻结批次整组隐藏。

## 近期标签页（Recent）
- 展示口径：`openAt > lastReviewedAt` 且仍未关闭的标签页（排除 pinned 与扩展页，包含空白页）。
- 操作能力：与“打开的窗口”一致，可复用列表组件。
- “已阅”操作：更新 `lastReviewedAt`，与气泡提醒保持一致。
- 筛选输入框：按标题/网址过滤近期标签页。

## 筛选输入框（Filter）
- 适用范围：打开的窗口、保存的列表、近期标签页、冻结历史四个标签列表页。
- 匹配规则：对标签/保存项的标题（title）与网址（url）做不区分大小写的包含匹配；关键词为空时展示全部。
- 两种模式（输入框旁切换，各页面独立记忆）：
  - 过滤模式：只显示匹配项；无匹配的窗口分组/冻结批次整组隐藏。
  - 跳转模式：保持完整列表，匹配行高亮；可在匹配项之间“下一个/上一个”循环跳转，列表自动滚动并强调当前匹配。
  - 切换模式后会自动跳到第一个匹配项（滚动在 DOM 高度更新之后执行，否则会被浏览器按旧高度夹住而跳不过去）。
  - 「过滤 / 跳转」的选择会**持久化**：管理页 4 个筛选框与侧边栏共用 `chrome.storage.local` 的 `filterMode` 键（全局一份），
    各页面初始化时读取，不做跨页实时同步。
  - 管理页保持"当前匹配项变化即自动滚动"；侧边栏因为要在滚动时同步当前项，关闭了该自动滚动并改为显式滚动，见 `docs/ui/firefox_sidebar.md`。
  - 匹配行高亮规则：**只有当列表里混有非匹配行时才高亮**。树状+过滤（祖先行是非匹配项）、跳转模式（完整列表）都会高亮；
    平铺+过滤时每一行都是匹配项，整表铺黄只是噪声，因此不高亮。
- 跳转交互：输入框内 Enter 跳下一个、Shift+Enter 跳上一个；输入框旁提供 ↑↓ 按钮与“第 n / 共 m”计数；无匹配时显示“无匹配”。
- 跳转范围：按当前列表渲染顺序遍历（查看“全部窗口”时自然跨窗口，查看单个窗口时仅在该窗口内）。
- 全选：过滤模式下仅作用于当前筛选结果；跳转模式下按完整列表全选。
- 性能与输入法：
  - 输入采用约 250ms 防抖（debounce），停止输入一小段时间后才真正过滤/计算匹配。
  - 输入法组合期（composition，如拼音候选的“临时字符”）不触发搜索与跳转，组合结束后再执行。
- 状态：各页面关键词与模式独立保留，切换页面不丢失；提供清空按钮（或按 Esc 清空）；刷新页面后重置。
- 空结果：过滤模式无匹配时展示“未找到匹配的标签页。”。

## 插件设置（Settings）
- AI 配置：端点、API 模式、Key、模型、单次上限、是否发送列表参考。
- 自动冻结：是否启用、闲置阈值、扫描间隔、每次上限、历史上限、白名单与匹配方式等。

## 弹窗交互
- 保存所选：选择目标列表或新建列表，支持写入描述与“保存后关闭”。
- AI 分组：触发分组与“应用分组生成新列表”。
- 移动标签：在列表间移动，支持新建目标列表。
- 移动窗口：将所选标签移动到指定或新建窗口。
- 新增列表：输入名称与描述完成创建。

## 反馈与状态
- 所有关键操作（保存、移动、冻结、导入导出）均返回状态提示（成功/失败）。
- 与后台通信统一通过 runtime message，确保 UI 与后台状态一致。
