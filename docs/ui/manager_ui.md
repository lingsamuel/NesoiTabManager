# 管理界面（Vue）

## 布局结构
- 侧边栏：主导航（打开的窗口 / 保存的列表 / 冻结历史 / 近期标签页 / 插件设置）。
- 子侧边栏：在“窗口/列表”视图下显示窗口或列表的快速切换入口。
- 主内容区：各视图面板 + 多个操作弹窗。
- 大列表渲染：使用 `VirtualList` 进行虚拟滚动，保证海量标签可用性。

## 打开的窗口（Windows）
- 列表展示：按窗口分块显示标签，包含图标、标题、URL、固定/冻结标识与冻结次数。
- 选择操作：支持全选/清空、行点击切换选中、复选框精确选择。
- 批量动作：关闭所选、冻结所选、移动到窗口、保存所选、AI 分组。
- 过滤能力：可隐藏已冻结标签页（便于聚焦活跃标签）。
- 拖拽交互：
  - 拖拽标签到另一个标签上，会插入到该标签之后。
  - 拖拽已选标签时，会整体移动选中集合。
- 单条动作：行内支持关闭与手动冻结；点击标题/URL 会激活该标签。

## 保存的列表（Lists）
- 列表切换：子侧边栏显示全部列表与数量；支持新增列表入口。
- 列表标题编辑：点击标题进入编辑态，可保存或取消。
- 列表描述：单独面板维护描述信息，用于 AI 分组参考。
- 列表内容：
  - 行内复选框 + 点击选中，支持批量删除与移动。
  - 支持直接打开保存项（新窗口打开链接）。
  - 批量删除与删除列表带确认提示，单条删除即时生效。
- 导入/导出：
  - 导出为 JSON 文件。
  - 导入支持“合并/替换”两种模式。

## 冻结历史（History）
- 分批展示：按冻结批次分段，展示冻结时间与包含条数。
- 批量动作：全选/清空、关闭所选、AI 分组、保存所选、刷新。
- 行内动作：可对历史标签执行关闭或激活。
- 状态提示：刷新与错误提示在顶部状态条展示。

## 近期标签页（Recent）
- 展示口径：`openAt > lastReviewedAt` 且仍未关闭的标签页（排除 pinned 与扩展页，包含空白页）。
- 操作能力：与“打开的窗口”一致，可复用列表组件。
- “已阅”操作：更新 `lastReviewedAt`，与气泡提醒保持一致。

## 插件设置（Settings）
- AI 配置：端点、API 模式、Key、模型、单次上限、是否发送列表参考。
- 自动冻结：是否启用、闲置阈值、扫描间隔、每次上限、历史上限、白名单与匹配方式等。

## 弹窗交互
- 保存所选：选择目标列表或新建列表，支持写入描述与“保存后关闭”。
- AI 分组：触发分组与“应用分组生成新列表”。
- 移动标签：在列表间移动，支持新建目标列表。
- 移动窗口：将所选标签移动到指定或新建窗口。
- 新增列表：输入名称与描述完成创建。

## 反馈与状态
- 所有关键操作（保存、移动、冻结、导入导出）均返回状态提示（成功/失败）。
- 与后台通信统一通过 runtime message，确保 UI 与后台状态一致。
