# 快捷操作（右键菜单 + 悬浮组件）

## 扩展按钮行为
- 点击扩展图标会打开 `ui/manager.html`（管理界面）。
- 如果已存在管理界面标签页，会自动聚焦该窗口与标签。

## 右键菜单（页面上下文）
- 顶层菜单：
  - “保存到列表”
  - “关闭并保存到列表”
- 子项行为：根据现有列表动态生成子菜单。
- 空列表提示：无列表时展示“暂无列表”禁用项。
- 执行动作：点击后调用后台保存当前页面，可选关闭标签页。

## 页面悬浮组件（content script）
- 位置与触发：固定在页面左下角，鼠标靠近自动展开。
- 展开面板：展示现有列表与两种动作（保存 / 保存并关闭）。
- 空状态：列表为空时提示“暂无列表，请先在弹窗中创建”。
- 反馈方式：保存成功/失败时短暂闪烁文案反馈。
- 收起逻辑：鼠标移出后延迟收起，避免误触闪退。
