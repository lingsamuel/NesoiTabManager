# AI 分组

## 目标与输入
- 面向大量标签的快速归类能力。
- 输入字段：标题、基础域名、打开顺序（index），可选已有列表名称/描述作为参考。

## 配置项（设置页）
- API 端点、API 模式（Responses / Codex / Chat）、API Key、模型名称。
- 单次最多标签数（超出则截断）。
- 是否发送已有列表标题/描述作为参考。

## 操作流程
1. 在“打开的窗口”或“冻结历史”中选择需要分组的标签。
2. 打开 AI 分组弹窗并点击“AI 分组”。
3. 生成的标签会显示在列表行内，提示分组结果。
4. 点击“应用分组生成新列表”会创建新列表（默认以“AI 分组：{标签}”命名，重名会自动加编号）。
   原列表不受影响。

## 标签级快捷操作
- AI 标签会显示在每条标签行右侧。
- 点击标签可将该条标签保存到对应分组列表。
- “保存并关闭”会在保存后关闭标签页。
- 若分组名与已有列表同名，则复用原列表；否则新建。

## 错误与边界
- 未选择标签或未配置 AI 会提示错误。
- 超出上限的标签会被截断并提示数量。
- AI 输出异常时会提示解析失败或分组无效。
