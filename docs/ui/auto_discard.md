# 自动冻结与冻结历史

## 自动冻结机制
- 目标：自动丢弃闲置标签以释放内存（`chrome.tabs.discard`）。
- 调度方式：使用 `chrome.alarms` 周期扫描，默认 3 分钟。
- 冻结条件：
  - 非当前激活标签、未被手动冻结、非特殊协议页面。
  - 可配置是否允许冻结已固定或正在发声的标签。
  - 闲置时间超过阈值。
  - 白名单命中时跳过（支持域名 / URL / 完整链接，且可选正则模式）。
- 批量控制：每次扫描最多冻结 `batchLimit` 条。

## 冻结历史
- 冻结记录按批次保存，并记录冻结时间、URL、标题与冻结次数。
- 冻结次数会在行内徽标提示“第 N 次冻结”。
- 历史上限可在设置中控制，超出时会裁剪最早记录。

## 手动冻结交互
- “打开的窗口”视图支持对单条或批量标签执行冻结。
- 结果反馈：成功/失败均在状态栏提示。

## 冻结历史视图交互
- 支持全选/清空、关闭所选、AI 分组、保存所选、刷新。
- 行内支持激活标签与关闭标签。
- 若自动冻结未开启，会提示需要先在设置中启用。

## 配置项（设置页）
- 启用开关、闲置阈值、扫描间隔、批量上限、历史上限。
- 允许冻结已固定 / 正在发声。
- 白名单匹配方式与正则匹配开关。
