# 0.2.9 变更说明（管理页布局 / 近期提醒开关 / 侧边栏管理按钮）

本次交付按需求分三组，共 7 项。这份说明是**临时交付说明**，不是设计文档；
后续如果要长期保留这些行为约定，应把「固定按钮位置」「上次分组记忆」「管理页 pinned 化」三节并入
`docs/ui/manager_ui.md` 与 `docs/ui/firefox_sidebar.md`（本次经确认跳过文档更新）。

## 一、功能与交互变更

### 1. 近期标签页提醒总开关（默认开启）

- 设置页「近期标签页提醒」面板顶部新增复选框「启用页面气泡提醒」，写入
  `chrome.storage.local.recentTabsConfig.reminderEnabled`，**默认开启**。
- 关闭后：
  - 后台清掉 `recentTabsReminder` 定时器（`chrome.alarms.clear`），不再周期性广播气泡；
  - 已经显示在网页上的气泡**立即消失**（由开转关时主动补播一次 `count:0` 的隐藏消息）；
  - 手动切换到其它标签/窗口也不会再弹出气泡；
  - **管理页「近期标签页」页签仍照常展示与统计，「已阅」行为不变**——关的是"提醒"，不是功能。
- 兼容：老数据没有该字段时按 `true` 处理（`sanitizeRecentConfig` 只在 `typeof === "boolean"`
  时才采纳），升级后行为与升级前一致。
- 新存储键：`listTargetMemory`（见第 4 项）；`recentTabsConfig` 新增字段 `reminderEnabled`。

### 2. 「保存的列表」行为与排版对齐「打开的窗口」

- 标题字号 `12px` + `font-weight: 600` → `11px` 常规字重，与标签行一致（不再是"整列粗体"）。
- 行高由「外层 64px + `.list-item` 撑满 100%」修正为「外层 64px 行高 + 内容盒 60px」，
  行与行之间恢复 4px 间距；`.list-title`/`.list-url`/`.list-meta` 的层级与标签行一致
  （11px 标题 / 10px 灰色网址 / 9px 灰色保存时间，保存时间按要求保留）。
- **新增搜索匹配刻度**：保存列表此前完全没有滚动条轨道刻度；现在复用与标签视图同一套
  `buildTrackMarkers` 纯逻辑与 `track_marks.css`，因此跳转模式下有琥珀色匹配刻度、
  当前匹配加深、密集时自动合并，点击刻度会滚到该行并在跳转模式下同步「当前项」。
- 保存项**不显示**冻结点/冻结次数/关闭按钮，也**不参与**拖拽排序（列表项状态只有
  url/title/savedAt，这些列在语义上不成立）。因此本次未新增任何后台重排消息。
- 空状态文案三分：有关键词 → "未找到匹配的标签页。"；没有列表 → "暂无已保存的列表。"；
  选中列表为空 → "该列表暂无保存的标签页。"。
- 描述面板的「清空」按钮改名为「清空描述」，避免与列表选择的「全不选」混淆。
- 实现方式：新增 `src/manager/components/ListsPanel.vue`，而不是把保存项硬塞进
  `TabListPanel`（后者的行模型是"活标签"，带 active/pinned/discarded/父子/冻结/关闭）。

### 3. 按钮位置固定（「打开的窗口」与「保存的列表」）

- 「清空」→「全不选」（四个标签列表页统一：打开的窗口 / 保存的列表 / 近期标签页 / 冻结历史）。
  只有需求指定的两个页面改了布局，近期标签页与冻结历史保持原有单行布局。
- **打开的窗口**
  - 标题行右侧：树状 / 平铺；
  - 第一操作行：左侧筛选框（过滤/跳转 + 计数 + ↑↓），右侧右对齐「全选 / 全不选 / 关闭所选」；
  - 第二操作行：左侧「隐藏已冻结」，右侧右对齐「保存所选 / 移动到 / 冻结所选 / AI 分组」。
- **保存的列表**
  - 标题行右侧：删除列表 / 导出列表 / 导入列表；
  - 第一操作行：左侧筛选框，右侧右对齐「全选 / 全不选 / 删除所选 / 移动所选」。
- 实现：动作拆成「跟标题同行」的 `.title-actions` 与「跟筛选框同行」的 `.filter-actions`，
  后者带 `margin-left: auto` 且组内 `flex-wrap: nowrap`——筛选框无论变多宽，这组按钮都贴右边缘，
  换行只可能发生在"筛选框"与"整组按钮"之间，组内相对位置不再漂移。
- 顺带修掉 `.content-header` 的 `margin-bottom: 12px`：外层 `.view` 已有 `gap: 12px`，
  两者叠加会在标题与筛选行之间留出 24px 空带。

### 4. 记住上次选择的分组

- 「保存所选」与「移动到」两个弹窗**各自记忆**上次真正用过的目标列表，存
  `chrome.storage.local.listTargetMemory = { save, move }`。
- 恢复时机：打开管理页 / 列表变化后（`loadLists`），只在用户本次会话**还没手动选过**时才写回，
  避免异步读盘回来把用户当下的选择改掉。
- 回退规则：记忆的列表已被删除 → 显示「新建列表」；「移动到」的记忆恰好是当前列表 → 也回退
  （后台会拒绝"移动到自身"）。
- 「新建列表」这个占位选择本身不写盘（否则会把上一次真正用过的分组顶掉）；但**保存/移动成功后**
  会把后台回传的真实 `listId` 记为记忆，所以"上一次新建的列表"下次会被直接选中。
- 写入用一条 promise 链串行化：两个弹窗几乎同时选择时，避免"读—改—写"交错互相覆盖。
- 该模块（`src/manager/utils/list_target_memory.js`）读写全部吞异常，storage 失败只会退化为"不记忆"，
  不影响保存/移动主流程。

### 5. 快捷保存气泡的空隙与悬停

- `.ntm-panel` 的 `bottom` 从 `78px` 降到 `74px`（hotzone 72px）：视觉缝隙由 6px 缩小到 2px，
  按要求保留少量缝隙。
- 悬停判定不再只用 `:hover`：`mousemove` 记录指针坐标，`isPointerOverWidget()` 用
  `getBoundingClientRect` 判断指针是否落在气泡矩形或「面板矩形外扩 8px」的桥接带内。
  指针划过硬缝、或从面板滑到「存」按钮再滑回来，都不会被判定为"已移出"。
- 细节：面板关闭时虽不可见但仍占布局，因此关闭态只认气泡本体，避免指针从气泡上方掠过就误弹面板。
- 细节：指针移出文档/窗口（`mouseleave` / `blur`）时让坐标失效并主动检查一次，
  避免最后一帧停在面板内导致面板再也收不起来。
- 拖动、点击展开浮层、`recentReminder` 消息处理等行为未改动。

### 6. 侧边栏「管理」按钮 pinned 化

- 点击「管理」不再无条件新建页面：先查是否已有管理页标签（`ui/manager.html` 与
  `ui/manager.html?mode=overlay` 两种形态各一次精确 URL 查询），命中则
  **先聚焦它所在窗口、再激活标签**，与扩展图标点击行为一致。
- 没有时才新建，并且**像 pinned 标签**：
  - 宿主窗口已有固定标签 → `{ pinned: true }`（不指定 index，不打断用户已有固定区排列）；
  - 宿主窗口一个固定标签都没有 → `{ index: 0, pinned: true }` 落到最左
    （否则浏览器会把它插到当前标签之后，看起来完全没被固定）。
- 查询失败或拿不到宿主窗口 → 降级为普通 `chrome.tabs.create({ url })`，不报错、不丢功能。
- 不做"把已有普通标签动态改成 pinned"，避免破坏用户标签状态。
- 性能：用两次精确 URL 查询 + 一次「本窗口固定标签」查询替代原先方案里的全量 `tabs.query({})`，
  10K 标签下不再有整表序列化开销。

### 7. 快速定位到当前标签页

- 侧边栏工具栏「＋」与「管理」之间新增「定位」按钮：把当前活动标签所在行滚动到可视区并居中。
- 行号复用已有的 `activeRow`（活动标签被折叠或被筛选隐藏时会指向它最近的可见祖先）；
  固定标签不在行序列里时给状态提示「当前标签页不在列表中。」而不是静默失败。
- 跳转模式下若该行本身就是匹配项，顺带同步「当前跳转项」，让 ↑/↓ 从眼前这一项继续；
  其余情况不动搜索状态。
- 蓝色刻度**保留**：命中区改用透明伪元素 `::after` 扩大（视觉仍是 3px 细条，
  命中高度 3px → 13px，横向各扩 1px 补满 14px 轨道），管理页与侧边栏共用同一份样式。
- 侧边栏工具栏行允许换行，避免窄侧边栏 + 跳转模式下三个按钮被挤压。
